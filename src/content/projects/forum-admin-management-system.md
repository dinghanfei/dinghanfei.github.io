## Overview

A Flask-based full-stack forum system with an integrated administrator backend. The system supports user registration, login, post publishing, commenting, topic-based discussion boards, and keyword-based fuzzy search.

## Implementation

I developed the frontend using HTML, CSS, and JavaScript, and implemented the backend with Flask, MySQL, and Redis. The system allows users to participate in discussions across different boards, while administrators can manage users and forum content through a dedicated backend management system.

## Tech Stack

Flask, MySQL, Redis, HTML, CSS, JavaScript.
